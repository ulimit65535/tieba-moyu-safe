# 百度贴吧优化摸鱼体验（本地安全评审版）

保存在 Chrome / Tampermonkey 中使用的本地脚本，保留原作者 Moyu 和 MIT 许可声明。当前版本：**2.0.5.5**。

[安装 / 更新脚本](https://raw.githubusercontent.com/ulimit65535/tieba-moyu-safe/main/tieba-moyu.user.js)

## 安装与使用

1. 在 Chrome 安装并启用 Tampermonkey，点击上面的脚本链接，然后选择安装或更新。
2. 刷新已经打开的贴吧页面。按 **R** 开启 / 关闭 Excel 伪装模式。
3. 点击「⚙ 设置」，开启「自动翻页」，再点击「保存配置」；自动翻页立即生效。
4. 关闭设置面板，在表格内向下滚动，接近底部会追加下一页楼层。也可以使用「上一页 / 下一页 / 跳转」切换单页；到最后一页自动停止。

更新使用原脚本的名称与 namespace，会替换同一个脚本并保留油猴存储的配置。没有开启自动远程更新，后续版本需手动更新。

## 本次修复

- 工作表仅从“我的贴吧”区域采集，不再将全页导航和推广入口（如“应用中心”“手游先锋”“玩家认证”）误加为工作表；个人区域中的同类功能入口也会排除。
- 首页“来源”保留可点击的贴吧链接；初始推荐和加载更多均可跳转，兼容 UTF-8 / GBK 吧名地址。
- 保留 Chrome 已安装的 2.0.5.3 中 Excel / 腾讯文档外观选择和即时切换功能。

- **帖子仅显示 30 楼、总页数恒为 1：** 旧版只在 `.l_pager` 内寻找「共 X 页」，但贴吧把总页数放在兄弟节点 `.l_reply_num`。现在综合回复统计、`max-page` 和同帖分页链接读取总页数，支持从贴吧列表内打开帖子、直接打开中间页、跳转尾页。
- **设置滑块无法打开：** 原滑块是没有绑定复选框的 `span`。改用关联的 `label`，点击滑块或文字均可切换。
- **自动翻页无效：** 旧版监听隐藏的原网页。现在以 Excel 滚动区域为观察根，使用当前工作表的下一页地址；帖子追加下一页内容并保持滚动位置。
- 优先读取贴吧真实楼层号，避免删楼或只看楼主时使用固定 30 条推算楼层。
- 翻页保留 `see_lz` 等查询参数；请求失败、返回验证页或错误页码时保留已加载内容并释放加载锁，支持手动重试。
- 异步请求完成时检查当前工作表，避免覆盖用户已经切换到的工作表。

## 请求与权限

沿用原有的四项油猴存储和菜单权限；没有新增 `@require`、`@connect`、`unsafeWindow` 或跨域请求权限。帖子请求仍限制为 `https://tieba.baidu.com` 同源 GET，携带同源登录状态并禁止重定向；新增 HTTP 状态检查和 20 秒超时。

本次未对原脚本的所有历史功能进行完整安全审计。原有图片预览、同源隐藏页面渲染等功能保留。
